One prose family, used across its full range rather than paired with a decorative face: documents should look like documents. The mono face is not decoration either. It carries sizes, dates and share tokens, the things a due-diligence room records rather than writes, and its tabular figures keep a column of file sizes from wobbling.

Elevation · hairline first

Chrome is flat and bounded by a hairline: panels, rows, inputs, the table.
Only things that float get the shadow: dialog, popover, toast, drag ghost. Four near-transparent layers, never a hard cast.

Errors say what happened and where, in the interface's voice. No apology, no "oops", and never a bare "invalid".

Rule. One size, one radius, one border. Focus is the shared outline drawn inside the edge rather than outside it, which is the only thing any control may change about it: a ring outside a full width field collides with the dialog holding it. Disabled drops to 45% and stops taking the pointer. Readonly keeps its border, because it is still a value you can select and copy, and only the monospace tells you it is not yours to edit.

The rail is the signature. A row whose access came from a folder above it carries a two-pixel rule, and the same rule runs up the breadcrumb to the ancestor that granted it. The rail answers one question only, "was this granted here or higher up"; which kind of share it is belongs to the chip. Nothing else on the page uses a coloured edge, so the eye reads inheritance without a legend. The difference between "shared" and "shared from above" is the question a data room actually gets asked, and it is the same distinction the access check makes in SQL.

Both modes live in one dialog because they answer the same question, and a person deciding who sees a folder should not have to find two places to look. The link is shown in the mono face: it is a token, not prose, and monospace makes a mistyped character visible. Someone invited before they have an account is labelled rather than hidden, since a room owner needs to know the invitation is out even though nobody has used it. Revoking is a single control in both modes, never buried behind a menu, because it is the one action that has to be fast.
