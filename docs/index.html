Data Room

A virtual data room: documents live in a private tree, and the owner decides who can see which part of it. Access granted on a folder reaches everything inside it and nothing beside it. Search finds a document by name anywhere a reader is allowed to look, and uploading over a name keeps what was there as a version. This page is the way into everything written about it.
