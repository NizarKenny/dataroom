Data Room API

This host answers the application, not people. Nothing here is a page: everything under it returns JSON, and almost all of it wants a token first.

GET/health Open. Says ok
GET/links/:token Open. The token is the credential
*/rooms /folders /files /shares Needs a signed in account

A node you are not allowed to see answers 404 rather than 403, deliberately: a 403 would confirm that a folder with that id is real.
